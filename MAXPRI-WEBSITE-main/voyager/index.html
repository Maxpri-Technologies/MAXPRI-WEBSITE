New in Voyager 6.0

One agent. Two ways to work.

Voyager started as a browser agent. Version 6.0 adds a second mode — and sharpens the first.

NEW

Code mode

Connect a project folder and tell Voyager what to build or fix. It maps the folder, reads the files that matter, and proposes edits you approve one at a time.

See how it works →
UPGRADED

A smarter browser agent

The agent loop was improved: dependent steps — click the search box, type, submit — now run as a batch before Voyager re-reads the page, so tasks finish with less back-and-forth.

See the new loop →
AUTOMATIC

It knows which mode you need

Agent mode works in your active browser tab. Code mode works in your connected folder. Ask for a source-code change and Voyager switches modes for you.

Agent mode · research the docs in your browser → Code mode · apply the change in your project → You review and approve each file

Code mode

It doesn't just browse. It builds.

Give Voyager one folder and a goal. It works through your project the way a careful teammate would — look first, then propose, then wait for your yes.

  • ✓You pick one folder. Choose it from the + menu beside the microphone. Voyager works inside that folder and nothing else.
  • ✓Looks before it leaps. It maps the folder structure first, then reads the files most likely to matter before it plans a change.
  • ✓Skips the noise. Dependency and build folders like node_modules, dist, and .git are left alone.
  • ✓You approve every write. Each file it creates or replaces pauses on a review dialog showing the exact path and proposed content.
  • ✓It never deletes files.

Safety

You're always the one holding the wheel

Runs locally

Page processing happens on your machine. Your browsing data doesn't get shipped off to run the agent.

Human-in-the-loop, always

Voyager is a co-pilot, not an unsupervised script — it stops and asks before anything with real consequences.

One folder, nothing else

Code mode only sees the single folder you connect, and you can disconnect it any time. Voyager asks for no extra system-wide filesystem permission. Files it reads are sent to the AI service to complete your task, so pick a folder you're comfortable sharing.

Every write is reviewed. No deletes.

Creating or replacing a file always pauses on a review dialog with the exact path and content. Voyager never deletes files.
